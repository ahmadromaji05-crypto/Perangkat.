Identitas & Kurikulum

Mode: Mesin Generator Dokumen Cepat (Luring/Tanpa API)

Cara Pasang di GitHub Anda:

  1. Buat repositori baru di GitHub (misal: modul-ajar-app).
  2. Unggah berkas ini dengan nama index.html.
  3. Buka menu Settings → Pages.
  4. Pilih Branch main lalu simpan (Save).
  5. Tautan aplikasi Anda siap digunakan dan dibagikan secara gratis!

Perangkat Belum Disusun

Silakan lengkapi formulir di sebelah kiri atau klik tombol "Contoh Otomatis" lalu tekan tombol susun.

Pengaturan Mesin Penyusun

Aplikasi ini memiliki dua mode kerja:

  • Generator Terstruktur Instan: Bekerja langsung secara offline di browser tanpa perlu kunci API, menyusun sintaks ajar sesuai standar Kemdikbud.
  • Didukung AI Gemini: Jika Anda memasukkan Gemini API Key, modul ajar akan dikarang secara kontekstual dan mendalam oleh model cerdas Gemini.
Kunci disimpan aman hanya di browser lokal Anda (Local Storage).
